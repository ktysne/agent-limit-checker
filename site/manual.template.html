1. 動作環境と導入

Windows 10 または Windows 11 の x64 環境で動作します。.NET ランタイムはアプリに含まれるため、別途インストールする必要はありません。

zip を展開し、AgentLimitChecker.exe を起動します。Claude Code または Codex の CLI にログイン済みであれば、利用量を取得します。アプリはシステムトレイに常駐します。

2. ポップオーバー

トレイアイコンをクリックすると、利用状況をまとめたポップオーバーが開きます。サービスごとの枠、使用率、リセットまでの時間を表示します。取得中やエラーがある場合は、その状態とログインなど次の操作を確認できます。

右上の歯車ボタンで設定パネルを開き、更新ボタンで利用量をすぐに取り直します。ポップオーバーの外をクリックするか Esc キーを押すと閉じます。

3. サービスごとの表示

Claude

Claude Code の 5時間枠と週次枠の使用率、リセット時刻を表示します。利用可能な場合は、クラウドセッション用クレジットの残高と有効期限も表示します。右上の鍵ボタンからログイン用のターミナルを開けます。

Codex

検出した Codex ホームをアカウントごとに表示します。それぞれの 5時間枠と週次枠、リセット時刻を確認できます。利用可能な場合は、リセット権の残り回数と最も早い有効期限も表示します。

Codex の設定にある「Codex 表示名」でアカウントごとの名前を指定できます。空にすると、ホーム名から作られた既定の表示へ戻ります。ポップオーバーとトレイの表示、通知文に同じ名前を使います。

ログイン済みのアカウントがまだ検出されない場合は、既定ホームにログインするボタンが表示されます。

4. 週次枠の配分目安

週次枠の残り日数が 2 日以上のとき、現在の使用率から見た今日の目安と、残り日数で均等に使う場合の割合を表示します。表示例は「今日あと 20.0% · 4日均等なら10.0%/日」のようになります。

今日の目安を超えている場合は「今日の枠 超過」と表示します。この数値は現在の使用率を日数で割り振った目安で、利用量の上限やリセット時刻を変更するものではありません。

5. 設定パネル

起動時にアップデートを確認起動時に新しいバージョンを確認します。オフでも「アップデートを確認」ボタンから手動で確認できます。
アップデートを確認確認中や結果をボタンの下に表示します。新しい版があれば更新の案内が開きます。
Codex 表示名各 Codex ホームの表示名を設定します。空にすると既定名を使います。

6. トレイのメニューとログイン

トレイアイコンを右クリックすると、Claude と Codex 各アカウントの 5時間使用率が表示されます。続けて「詳細を表示」「今すぐ更新」、ログイン、自動起動、更新間隔、「終了」を選べます。

「claude login (新しいターミナルで実行)」または Codex のログイン項目を選ぶと、新しいターミナルで CLI のログインを開始します。Codex の各ホームは個別に選べます。見つからない既定ホームは、作成してログインする項目として表示されます。

設定パネルとトレイの「ログイン時に自動起動」は同じ設定です。更新間隔も設定パネルまたはトレイの「更新間隔」から変更できます。

7. ntfy 通知

スマートフォンなどで ntfy の Topic を購読し、その Topic URL を設定します。認証が必要なサーバーでは Access token を追加します。通知の種類は次から選びます。

  • 5時間リセット
  • 週次リセット
  • Codex リセット権の期限

リセット権の期限は、最も早い期限の 5 時間前に通知します。期限まで 5 時間を切っている場合は、有効期限内ならすぐに通知します。設定を変更すると通知の登録も更新されます。

8. 自動アップデート

「起動時にアップデートを確認」が有効な場合、起動時に最新版を確認します。設定パネルの「アップデートを確認」からも調べられます。新しい版が見つかると、トレイのメニューと更新の案内に表示します。

自動適用できる環境では、案内から更新を始めると zip のダウンロード、SHA-256 の照合、ファイルの展開、アプリの再起動を行います。更新中は進行状況を表示し、途中で失敗した場合は元のファイルへ戻します。

アプリのフォルダーへ書き込めない場合など、自動適用できない環境ではブラウザーで配布 zip を開きます。zip を展開して更新してください。

9. 3.x からの移行

3.x（Electron 版）には自動アップデートがありません。4.0.0 を一度ダウンロードし、展開したフォルダーへ入れ直してください。設定とログはそのまま引き継がれます。

更新後に以前のファイルが残っている場合は、古い実行ファイルを起動しないよう、展開先を空にしてから新しい zip を展開してください。
