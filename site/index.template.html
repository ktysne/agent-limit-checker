Agent Limit Checker は Windows のシステムトレイに常駐し、Claude Code と Codex の利用量をまとめて表示します。

5時間枠と週次枠の使用率、リセットまでの時間、利用可能なクレジットをひと目で確認できます。複数の Codex ホームも個別に表示します。

Agent Limit Checker をダウンロード v{{VERSION}} マニュアルを読む

Windows 10 / 11（x64）が必要です。.NET ランタイムのインストールは不要です。

主な機能

  • 5時間枠と週次枠を表示
  • Codex の複数アカウントに対応
  • 週次枠の配分目安を表示
  • 通知と更新を設定

利用量をまとめて確認

トレイのアイコンからポップオーバーを開くと、各サービスの使用状況と設定を確認できます。

使用率とリセット時刻

Claude と Codex の 5時間枠、週次枠の使用率とリセットまでの時間を表示します。

Codex の複数ホーム

検出した Codex アカウントを個別に表示し、表示名をホームごとに設定できます。

週次枠の配分目安

週次枠の残り日数に合わせて、今日の目安と残り日数で均等に使う場合の割合を表示します。

必要な情報を通知

ntfy でリセット時刻や Codex のリセット権の期限を通知できます。起動時の更新確認と自動起動も設定できます。

使い方

CLI のログイン情報を使って利用量を取得し、システムトレイに表示します。

  1. Claude Code と Codex にログインする

    利用する CLI でログインしてください。アプリからログイン用のターミナルを開くこともできます。

  2. トレイから使用状況を見る

    トレイアイコンをクリックすると、サービスごとの使用率、リセット時刻、クレジットが表示されます。

  3. 必要に応じて設定する

    更新間隔、自動起動、通知、Codex アカウントの表示名を設定パネルで変更できます。
