# Agent Limit Checker

Agent Limit Checker は Windows のシステムトレイに常駐し、Claude Code と Codex の利用状況を表示するアプリです。

## 主な機能

- Claude と Codex の 5 時間枠および週次枠の使用率とリセット時刻を表示します。
- 週次枠の使用率から、今日の利用ペースの目安を表示します。
- Codex の複数ホームをアカウントごとに表示し、表示名を設定できます。
- Claude のクラウドセッション用クレジットと Codex の利用可能クレジットを表示します。
- 利用状況のリセット時刻と Codex のリセット権の期限を ntfy で通知します。
- 新しい版を確認し、配布 zip の検証後にアプリを更新します。

## 動作環境

Windows 10 または Windows 11 の x64 環境で動作します。
アプリには .NET ランタイムが含まれるため、別途インストールする必要はありません。
利用状況を取得するには Claude Code または Codex の CLI にログインしてください。

## 導入

[Agent Limit Checker の配布ページ](https://ktysne.info/agent-limit-checker/)から zip を取得して展開し、`AgentLimitChecker.exe` を起動してください。
アプリはシステムトレイに常駐します。

## 3.x からの移行

3.x の Electron 版には自動アップデートがないため、4.0.0 を配布ページから一度取得して入れ直してください。
3.x と 4.0.0 は単一インスタンスの制御を共有しないため、設定と CLI の資格情報が競合しないよう、移行前に Electron 版を終了してください。
設定ファイルとログは同じ場所を使うため、移行後も引き継がれます。
古い実行ファイルを誤って起動しないよう、展開先を空にしてから新しい zip を展開してください。

## 基本的な使い方

- トレイアイコンをクリックすると、使用率、残り時間、取得状態をまとめたポップオーバーが開きます。
- ポップオーバーの歯車ボタンから更新間隔、自動起動、起動時の更新確認、ntfy 通知、Codex の表示名を設定できます。
- ポップオーバーの鍵ボタンまたはトレイメニューから Claude と Codex のログインを開始できます。
- トレイアイコンを右クリックすると、利用状況、詳細表示、今すぐ更新、ログイン、自動起動、更新間隔、終了のメニューが開きます。
- 自動起動を有効にすると、Windows へのログイン時にアプリが起動します。
- ntfy アプリで Topic を購読し、その Topic URL を設定すると、5 時間枠と週次枠のリセット、および Codex のリセット権の期限を通知できます。認証が必要なサーバーでは Access token も設定してください。
- 起動時の確認が有効な場合は新しい版を起動時と 24 時間ごとに確認します。設定画面から手動でも確認できます。

## 設定とログの保存先

| 種別 | 保存先 |
| --- | --- |
| 設定 | `%APPDATA%\agent-limit-checker\settings.json` |
| ログ | `%APPDATA%\agent-limit-checker\logs\agent-limit-checker.log` |

## トラブルシュート

- Claude の認証エラーが続く場合は、ターミナルで `claude login` を実行してください。次の取得時に資格情報を読み直し、refresh に失敗した場合はエラーに理由を表示します。
- Codex が見つからない場合は、Codex CLI をインストールしてから再度起動してください。npm でインストールする場合は `npm i -g @openai/codex` を実行します。
- ログインボタンから CLI を起動できない場合は、CLI の実行ファイルを `CLAUDE_PATH` または `CODEX_PATH` に設定してください。
- 詳しい動作記録は設定と同じフォルダーの `logs\agent-limit-checker.log` にあります。
- 一時フォルダーから起動した場合やインストール先に書き込めない場合、自動適用は行われません。配布ページから zip を取得して展開してください。
